# PHAROS release notes

## 0.8

Initial public release series: integrated AI chat, Knowledge Bases with vector and lexical retrieval and citations, offline Kiwix library, offline maps and geographic search, GPX and waypoints, persistent jobs, bilingual interface, configuration and diagnostics, Ubuntu updates and experimental Windows installer. Trusted LAN/VPN deployments only. No road routing or application authentication.

See the README and user manuals for platform support and installed version.
