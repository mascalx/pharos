# Contributing to PHAROS

Contributions are welcome. Describe the problem and expected behavior, include the installed version, operating system and reproducible steps. Do not include credentials, private documents, logs containing personal data or private infrastructure details.

For code changes, use a separate branch, keep changes focused, preserve existing data and configuration, and add regression tests. Run `bash scripts/test-local.sh` in a development environment with Python, the project test dependencies and Node.js. Document platform limitations and distinguish automated tests from real-device tests. Do not submit bundled third-party binaries or content without checking redistribution terms. Contributions to original PHAROS code are subject to the repository's Apache-2.0 license.

For vulnerabilities, follow [SECURITY.md](SECURITY.md).
